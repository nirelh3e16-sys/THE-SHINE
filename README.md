# THE SHINE

**English** · [Русский](README.ru.md)

*A top-down roguelike shooter about a perfectly ordinary guy whose bedroom curtains open onto the end of the world.*

THE SHINE is a 2D action roguelike written in Python + Pygame. Every sprite, effect and sound is generated by code — no external assets, no internet, no keys needed. Fight through five strange locations, collect cursed gifts, decide who you are, and face the thing that started it all.

## The idea

- **Every gift demands a sacrifice.** Strong items always come with a price — more damage but faster enemies, a shield that slows you when it breaks, wings that burn your speed when you land. No run should be "just stack damage": items change *how* you play.
- **Your choices are remembered.** Events and altars ask you to steal, help, fight or flee. Your sins and testimonies carry over between runs and unlock the secret ending.
- **A story told through bosses.** Each boss is a piece of the puzzle about THE SHINE — what it is, who it used to be, and what is above and below it.
- **Replayable by design.** Procedural rooms, a pool of 61 items, combos, hidden synergies, 8 playable characters and multiple endings.

## Quick start (Windows 10/11, Python 3.11+)

```
python -m pip install -r requirements.txt
python main.py
```

The game starts in English; switch to Russian in *Settings → Language / Язык*.

## The world

Locations, in order: **Forest → Suburbs → City → Center → The Gates (THE SHINE)**. Two secret side locations — **Hell** and **Heaven** — open after you have seen certain endings.

- Each location is a procedurally generated set of connected rooms: combat, treasure, shop, events and a boss room. Combat rooms lock until you clear them.
- **Mini-bosses** guard the way to each boss and drop unique items that cannot be found anywhere else.
- **Locations get weirder:** the City shifts gravity and rebuilds its walls, the Center glitches and patches rooms together from different places, Hell burns, Heaven's guards sleep until you touch one.
- **Bosses:** the Lumberjack, the Neighbor, the Mayor, Chaos, THE SHINE, the Imp and God — each with several phases and attacks that are always telegraphed first.
- **Day and night** cycle, dynamic shadows, sun glare and lights (all optional, *Settings → Graphics*).

## Characters

Rob (starting), the Lumberjack, Tom, the Big Shot, Glitch, the Angel, the Devil and the Soul. Each has different health, speed, size, starting items and sometimes special traits (the Angel walks through walls). Locked characters show their unlock condition — usually beating a boss several times, or reaching a certain ending.

## Items

**61 items** live in `data/items.json`. Each has a unique string `id` and a unique number (used by the console). Items can be passive or active (Q), combine into combos, and some drop only from mini-bosses.

### Version 1.1.0 — thirty artifacts

Ten Biblical, ten Old Slavic and ten Greek artifacts, in four rarities: **10 common, 10 uncommon, 7 rare, 3 divine**.

| | Biblical | Old Slavic | Greek |
|---|---|---|---|
| Theme | faith, sin, redemption | nature, spirits, fate | pride, heroism, the will of the gods |
| Examples | Seven Seals — a wave of light every 7 kills, but it slows you. Forbidden Fruit — +40% damage, faster enemies. Holy Grail — full heal on a boss kill, weaker healing otherwise. | Perun's Axe — every 5th attack calls lightning, the rest hit 10% weaker. Koschei's Needle — survive one lethal hit per floor, but lose max health for a while. Bone Mortar — a mortar crushes the room, then you cannot attack. | Fire of Prometheus — stronger, igniting fire that sometimes burns you. Pandora's Box — a random effect, maybe a room curse. Lightning of Zeus — a bolt along your aim line, then no attacks for 2.5 s. |

Highlights of how they work:

- **Flight:** Seraph's and Icarus's Wings turn the dodge into a short flight over obstacles; landing (or overheating) slows you.
- **Statuses:** Morana's Crown freezes, Medusa's Head petrifies, Prometheus's Fire ignites.
- **Actives:** Book of Revelation (prophecy, sometimes false), Bone Mortar, Pandora's Box, Helm of Hades (invisibility, but no attacks), Ariadne's Thread (return to the previous room), Lightning of Zeus.
- **Synergies:** pairs such as Seven Seals + Book of Revelation or Zeus + Perun change how items work. **Three secret synergies** exist for three-item sets — find them yourself.

## Endings

Several endings are tracked across runs (good, bad, secret, evil and true). Defeating bosses, the choices you make and the testimonies you collect decide which ones you can reach. Some unlock new characters and locations.

## Bestiary

*Bestiary* in the main menu records every boss, mini-boss, mob and item you have discovered. Entries unlock by defeating the creature or finding the item; hidden synergies are not spoiled.

## Developer console (F4 + 3)

Open it during a run. Unlike the test menu, **the console does not mark the run as a test run** — progress, bestiary entries and endings still count. The game is paused while the console is open.

| Command | What it does |
|---|---|
| `help [command]` | list commands / help for one |
| `give <id\|number> [...]` | give items, e.g. `give seven_seals` or `give 130` |
| `remove <id\|number>` | take an item away |
| `items [text]` | list all items with id, number, rarity and theme (filter by text, e.g. `items greek`) |
| `inv`, `combos` | carried items; all combos including hidden ones |
| `teleport <place>` (alias `tp`) | `forest`, `suburbs`, `city`, `center`, `shine`, `hell`, `heaven`, or a room of this location: `boss`, `miniboss`, `start`, `shop`, `treasure`, `event` |
| `locations` | list teleport targets |
| `god [on\|off]` | invulnerability |
| `damage <n>\|reset`, `maxhp <n>\|<h>h`, `hp <n>\|full`, `reset` | override damage / max health (`maxhp 6h` = 6 hearts), health |
| `coins <n>`, `coins set <n>` | add / set coins |
| `heal`, `card`, `killall` | full heal, three-card choice, kill every enemy in the room |
| `clear`, `close` | clear output, close console |

Tab completes commands, item ids and places; ↑/↓ browse history; PageUp/PageDown scroll.

## For developers

- Code is organised in `game/` (`entities/`, `systems/`, `world/`, `ui/`, `art/`); data in `data/*.json`. Artifact behaviour is in `game/systems/artifacts.py`, the console in `game/console.py`.
- **Adding an item:** add an entry (`id`, unique `num`, `name`, `desc`, `icon`, `color`, `mods`/`flags`/`active`) to `data/items.json`, draw its icon in `game/art/`, and add English text to `data/lang_en.json`.
- **Localisation:** the source language is Russian; the English translation is looked up by the Russian string at draw time in `data/lang_en.json`. A test fails if any player-visible string is untranslated.
- **Config:** `config.json` next to the game (rooms per location, window scale, seed, day length, `unlock_all_characters`, …). Saves and `crash.log` live in `saves/`.
- **Music:** put tracks in a `mus/` folder (`Forest_Combat.mp3`, `THE_SHINE.mp3`, `Hollow_Sanctuary.mp3`, `spawn_of_darkness.mp3`, …). Missing files just mean silence. See `game/systems/audio.py` for the full list.
- **Icon / Steam:** `icon.ico` next to `main.py` is used as the window icon; Steam achievements are optional (`requirements-steam.txt`).
- **Tests:** `python -m unittest discover tests`. Tests that need Pygame are skipped when it is not installed.
- **Build:** `.github/workflows/build.yml` runs the tests and builds a Windows version with PyInstaller on every push.
