# THE SHINE

2D roguelike / action shooter (вид сверху) на Python + Pygame. Все спрайты и звуки генерируются кодом — внешние ассеты, интернет и ключи не нужны.

## Установка и запуск (Windows 10/11, Python 3.11+)

```
python -m pip install -r requirements.txt
python main.py
```

## Управление
| Клавиша | Действие |
|---|---|
| WASD | движение |
| Мышь / ЛКМ | прицел / стрельба |
| Space или Shift | уклонение с неуязвимостью |
| E | взаимодействие (предметы, NPC, алтари, портал) |
| Q | активный предмет |
| Tab | инвентарь и журнал свидетельств |
| Esc | пауза (игра также ставится на паузу при потере фокуса) |
| F11 | полный экран |
| F4 + 1 | показать/скрыть счётчик FPS |
| F4 + T | тест-меню (только во время игры) |
| F4 + 2 | статистика персонажа: здоровье, урон, скорострельность, скорость, удача, временные баффы (только во время игры) |

## Что есть в этой версии
- Вступление (спальня → занавески → взрыв → THE SHINE), показывается при первой новой игре; Enter — пропустить.
- **Персонажи** (`data/characters.json`; «Новая игра» → выбор персонажа). Закрытые показывают условие открытия и прогресс. Победы над боссами считаются за все забеги (тест-режим не считается).
  - **Роб** — стартовый.
  - **Лесник** (10 побед над Лесником): Топор + Неисправный компас.
  - **Том** (10 побед над Соседом): большой и медленный, 6 сердец со старта (с Радионяней), Радионяня + Половина ядерной бомбы.
  - **Большая шишка** (10 побед над Мэром): 2 сердца, быстрее обычного, Игрушечный солдатик + Чайник под давлением.
  - **Глич** (10 побед над Хаосом): 1 сердце, очень быстрый, Старый телевизор + Чайник под давлением.
  - **Ангел** (10 побед над The Shine): стандартные сердца, проходит сквозь блоки, гравитация на него не действует, Дробовик.
- **Визуальные эффекты («шейдеры» на Pygame, без GPU-кода):**
  - Тени от игрока, мобов, NPC и боссов на открытых локациях (лес, пригород, город, центр): направление и длина зависят от положения солнца (утром длинные и вправо, в полдень короткие, вечером длинные и влево, ночью солнечных теней нет).
  - Блики и лучи солнца (тёплое сияние со стороны солнца, блики на линзе, световые лучи) при высоком солнце.
  - Свет излучают игрок, боссы (цвет у каждого свой), часть мобов в Аду и Центре, снаряды, взрывы, трещины лавы, врата, разлом и портал.
  - Смена дня и ночи (только визуально): забег начинается на рассвете, затем утро, пик солнца, закат, сумерки и ночь; длина суток — `day_length_seconds` в `config.json` (по умолчанию 480 с). В домах, Аду и Вратах солнца нет — там всегда темно, как ночью, зато виден собственный свет.
  - **Настройки → Графика и эффекты** (или «Графика» в меню паузы): общий выключатель шейдеров, тени (вкл/выкл и сила), блики солнца, свет игрока и боссов, время суток (по времени / всегда рассвет, день, закат или ночь), яркость ночи. Настройки сохраняются.
- **Инерция:** игрок и обычные мобы разгоняются и тормозят плавно (≈0.1–0.2 с).
- **Усиленные боссы:** Лесник (больше здоровья, быстрее, больше пил, веер пил после рывка и 3 дерева за раз), Мэр (больше здоровья, быстрее подписывает законы, ходит уже в первой фазе, больше выстрелов, врагов и падающих зон, спираль из 4 рук, налог 10 с), The Shine (900 здоровья: держит дистанцию и кружит, иногда уворачивается от снарядов, иногда взлетает и падает точно на отмеченную метку — в воздухе неуязвим).
- **Ад** (секретная ветка): после победы над The Shine при открытой секретной концовке в стене появляется дверь с разломом, в котором виден ад (рядом с вратами). Прыжок в разлом — локация «Ад»: базальт, лава течёт из трещин в стенах, всё полыхает; враги — адские гончие, огненные бесята, магматические големы, угольки, идолы пепла; алтарь сделок. Босс **Бес** (1400 здоровья, сильнее The Shine): комната босса пуста, пока не дойдёшь до центра; тогда стены обрушиваются, остаётся платформа посреди озера лавы, из лавы поднимается Бес и рассказывает, что The Shine был его сыном — падшим бесом, а не богом. Бой: огненные шары, дыхание (лучи), гейзеры, пике, волны лавы, метеориты, гончие из лавы, спираль, кольца огня, платформа сужается (край заранее мигает). Победа открывает персонажа **Дьявол**.
- **Дьявол** (открывается с первой победы над Бесом): 10 сердец, очень быстрый; предметы Компактный бес, Якорь, Крылья ангела.
  - **Душа** (открывается True Ending): белый призрак без рук и ног, чёрные пустые глаза. Полсердца (1 здоровье), скорость в 2 раза выше обычной, урон 7. Предметы: **Балансатор** (заменяет стрельбу: зажми атаку на 3 с и отпусти — гейзер душ длиной 25 блоков, он следит за курсором; недозаряд пропадает) и **Крик** (Q, 45 с: гигантский гейзер в 4 раза шире, держится 3 с вместо 1.4, бьёт сильнее, сметает вражеские снаряды и толкает игрока назад — отдача). Любой удар смертелен.
- **Ещё 8 предметов:** Граната (Q: бросок к курсору, взрыв диаметром 5 блоков, 50 урона всем внутри, 50 с), Аптечка (Q: всё здоровье, перезарядка — 5 убийств), Якорь (держи атаку — вертится вокруг, отпусти — летит к курсору, дальность до 10 блоков, огромный урон), Крылья ангела (сквозь стены + иммунитет к гравитации), Бита (аналог топора), Автомат (скорострельный), Сломанный телефон (Q: телепорт в случайную комнату локации, кроме босса, 20 с), Компактный бес (спутник: когда тебя ранят — нападает на врагов; если здоровья меньше половины — бьёт тебя и улетает навсегда).
- **Новые предметы:** Топор (широкий тяжёлый взмах с отбрасыванием) и Дробовик (пять дробин веером, перезарядка дольше).
- **Steam:** игру можно добавить в Steam как стороннюю (Библиотека → Добавить игру → Добавить стороннюю игру → `TheShine.exe`), оверлей открывается по Shift+Tab. Для оверлея игра выводит картинку через GPU (`"gpu_present": true` в `config.json`; при `false` возвращается программный вывод, без оверлея). Достижения Steam — необязательно: нужны пакет `steamworks` (`requirements-steam.txt`), `steam_api64.dll`, `SteamworksPy64.dll` рядом с игрой и настоящий AppID; без них модуль молча выключен. Для разработчика: `"unlock_all_characters": true` в `config.json` открывает всех персонажей.
- **Карточки:** при переходе в новую локацию (и из тест-меню) открывается выбор одной из трёх случайных карточек — видны только название и значок предмета, описание узнаёшь после выбора. Карточку можно найти и в комнате с сокровищами (иногда вместо предмета).
- **Главное меню:** название и кнопки в правом нижнем углу, фон — случайная локация (лес, пригород, город, центр или врата).
- Издатель и авторы музыки — **FreeDom Studio**.
- **Финал:** портал после Хаоса ведёт к THE SHINE: он обещает рай, смеётся и показывает, что устроил всё сам; иллюзия рассыпается, начинается бой. Три фазы: Ангел (световые веера, взмахи крыла, лазеры, нимбы), Судья (атаки прошлых боссов: косилки, падающие предметы, спираль, рывки, перестройка арены), Издевательство (временные правила — инвертированное управление, «медленно, но часто», гравитация; перестановка элементов интерфейса; комментарии по событиям: первый полученный урон, активный предмет, повтор атаки, предметы игрока). Все опасные атаки заранее показываются.
- **Концовки** (сохраняются в `saves/save.json`, в меню виден счётчик):
  - GOOD — победа над The Shine: «Ты всё ещё не заслужил это» … «Но, наверное, никто не заслуживает».
  - BAD — поражение от The Shine: «Ну... правила есть правила».
  - SECRET — победа над The Shine при наличии всех четырёх свидетельств (суммарно по всем забегам): «Крыло в углу» (событие в Лесу/Пригороде), «Лицо на билборде» (событие в Городе), «Вчера и позавчера» (событие со свидетелем) и «Проявленная фотография» (предмет «Пустая фотография» + две комнаты без урона). The Shine — бывший человек, прошедший то же испытание.
  - EVIL — победа над Бесом (портал после него): «ЭТО ЕЩЁ НЕ КОНЕЦ!»… Забег на этом заканчивается, титров нет. Открывает Небеса и персонажа Дьявол.
  - TRUE — победа над Богом: «Душа страдальца была отвергнута и светом, и тьмой»… Открывает персонажа Душа, показываются титры.
  - После GOOD, SECRET и TRUE показываются титры.
- **Тест-меню (F4 + T):** только в игре. Неуязвимость, значения урона и макс. здоровья, +10 монет, полное лечение, телепорт в комнату босса и переход в любую локацию (финальная арена — сразу с боя). Тест-забег не сохраняется и не даёт прогресса, концовок и свидетельств.
- Зона «Центр»: кислотные цвета, комнаты из кусочков разных мест (разные «лоскуты» пола и препятствий), вертикальные дороги, враги (летающие глаза, обломки зданий, глитчи, которые исчезают и появляются рядом — точка появления помечена), смещённые двери, гравитация и перестройка стен, события («Твоя спальня?», клерк бюро находок реальности), босс **Хаос**: фаза 1 — осколки, глаза, падающие обломки; фаза 2 — «правки реальности» (на 8 с меняются свойства твоего оружия, комната перестраивается и включается гравитация; всё подписано над боссом заранее); фаза 3 — часть интерфейса пропадает, звук и картинка дают сбой, добавляется спиральный обстрел. Здоровье, активный предмет и опасные зоны всегда остаются видны.
- Зона «Город»: враги (радиационные крысы, мутировавшие полицейские, военные дроны, живые машины, телевизоры-рекламщики), проёмы дверей смещены от середины стен, боевые комнаты с **изменённой гравитацией** (дрейф игрока, направление меняется с предупреждением) и **перестраивающимися стенами** (новая расстановка показывается мигающими контурами за 1.2 с), босс **Мэр**: подписывает законы (каждый заранее подписан на экране: наём врагов, снос, перестройка арены, налог на скорострельность; у каждого перезарядка), затем стол-монстр с рывками и бумажным взрывом, затем сюрреалистическая форма со спиральным обстрелом.
- Зона «Пригород»: враги (собака, почтальон, спринклер, тележка), комнаты-дома (E у двери) с мини-данжем из 3–4 комнат и наградой, события, босс **Сосед** (3 фазы: косилки по полосам с предупреждением → бытовая техника и падающие предметы → призыв соседей).
- **Небеса** (после злой концовки): когда игрок уже видел EVIL, после победы над The Shine рядом с вратами появляется белый портал в золотой оправе. Он **не завершает забег**, а переносит в локацию «Небеса». Видно только голубое небо: стен нет, комнаты — белые облачные острова, препятствия — парящие облака, двери в золотой оправе, **всегда день**. Враги Небес (херувимы, грозовые облачка, живые нимбы, голуби, трубачи, каменные ангелки) **не нападают первыми**: пока кого-нибудь не тронуть (выстрел, взрыв, касание), они стоят смирно, а когда тронули хотя бы одного — бой начинают все враги комнаты. Двери откроются только после боя, так что начинать его придётся самому. Перед комнатой босса стоит мини-босс **Хранитель врат**, после победы над ним открывается комната босса.
  - **Хранитель врат** (520 здоровья, каменная статуя ангела с весами): бьёт весами (круги ударов с предупреждением, дуга взмаха), призывает врагов локации (не больше 5). **Нужно держаться рядом**: если игрок дальше 130 пикселей от босса, тот восстанавливает здоровье (границу показывает кольцо вокруг него; оно краснеет, когда босс лечится). Награды нет.
  - **Бог** (финальный босс, 10 000 здоровья): существо с радиальной симметрией — единственный глаз и ряды крыльев вокруг него. Бой начинается с монолога; затем в игрока вселяется раненый Шайн, разрывает его тело, и **дальше играешь за Шайна: 1000 здоровья и 100 урона за выстрел** (полоска здоровья вместо сердец). Бог бьёт на 250 за любое попадание. Атаки (всё заранее показывается): кольца перьев, спираль, взгляд (очередь по линии), колонны света, кольцо со щелью, крест из полос, в третьей фазе — «нова» с закрытым глазом. Три фазы (66% и 33%). Во время боя забег не сохраняется.
- **Мини-боссы** (`game/entities/miniboss.py`): у каждого мини-босса своя зона, он стоит один в комнате **прямо перед комнатой босса** (на миникарте комната оранжевая; к боссу пройти можно только через неё). После победы в центре комнаты появляется пьедестал с наградой; у всех — полоска здоровья, вторая фаза на половине здоровья, слабое отбрасывание. Награды нельзя найти в магазинах, сокровищницах и карточках (`"drop_only": true` в `items.json`). Тест-меню: «Телепорт к мини-боссу».
  - **Живая ель** (Лес, 120 здоровья). Стреляет иголками: иголка не ранит сама, а застревает в игроке на 3 с, и пока она торчит, **каждое движение (каждые ~24 пикселя пути) ранит** (1 урона, а при трёх иголках и больше — 2). Замри или перекатись (во время переката иголки пролетают насквозь). Атаки: веер, кольцо, очередь; во второй фазе добавляются корни, которые вылезают под игроком с предупреждением (они наказывают за стояние на месте). Награда — **Колючка-пушка**: спутник стреляет колючками по ближайшему врагу; колючка застревает во враге на 3 с и ранит его при каждом его движении. **Колючка-пушка + Автомат = Шипастая ярость**: колючки летят в 1.7 раза быстрее и взрываются, когда исчезают.
  - **Домовладелец** (Пригород, 130 здоровья). Появляется в одном из домов (какой именно — зависит от сида забега), в комнате перед комнатой с наградой. Кидает в игрока собак (не больше 4 живых). Во второй фазе включает телевизор: **каждые 5 секунд** за секунду до выстрела начинаются помехи (интерфейс «рвёт»), затем телевизор выстреливает кластером из 10 снарядов. Награда — **Старый пульт**: твои снаряды самонаводятся на ближайшего врага. **Старый пульт + Старый телевизор = Переключение каналов**: вместо монет с врагов выпадает случайный предмет (его нужно подобрать; награды мини-боссов в этот пул не входят).
  - **Боевой танк** (Город, 160 здоровья). Постоянно едет к игроку и **каждые 5 секунд** стреляет гранатой: место падения мигает красным 1.1 с, взрыв наносит 2 урона. Во второй фазе — три гранаты за залп и ход быстрее. Награда — **Бронежилет**: +3 сердца и поглощает 40% получаемого урона (в среднем, дробный остаток переносится на следующий удар).
- Портал после Лесника ведёт в Пригород, после Соседа — в Город, после Мэра — в Центр (здоровье, предметы и монеты сохраняются), после Хаоса — экран «демо».
- Зона «Лес»: процедурные связанные комнаты (количество — в `config.json`, `zones.forest.rooms`, 5–20), бой, сокровища, магазин, события, босс **Лесник** (2 фазы), портал после победы.
- 29 предметов (`data/items.json`, из них 3 — награды мини-боссов) и 6 комбинаций; грехи и журнал свидетельств; события с выбором (`data/events.json`); сохранения в `saves/save.json` (мета-прогресс + «Продолжить»).
- Звук: процедурные сигналы; можно положить свои `shoot.wav`, `hit.wav`, `hurt.wav`, `pickup.wav`, `door.wav`, `boss.wav`, `death.wav`, `story.wav`, `nuke.wav`, `dodge.wav`, `buy.wav` в `assets/audio/`.

- `spawn_of_darkness.mp3` — бой с любым боссом;

## Язык
По умолчанию игра на **английском**. Русский включается в «Settings → Language / Язык» (подпись переключателя всегда на двух языках); выбор сохраняется. Текст игры написан по-русски, а перевод подставляется при отрисовке по словарю `data/lang_en.json` (ключ — русская строка, `{}` — подставляемое значение): строки с `{}` работают как шаблоны, части внутри переводятся отдельно, а склеенные строки переводятся по известным фразам. Незнакомая строка показывается как есть. Новую строку в игре достаточно добавить в словарь: тест `LocalizationTests` проверяет, что в английском режиме не осталось ни одной непереведённой русской строки из кода и данных.

## Бестиарий
Раздел главного меню («Bestiary»): вкладки «Боссы», «Мини-боссы», «Мобы», «Предметы». Запись открывается **победой** над существом (моб, босс или мини-босс) или находкой предмета; закрытые записи показывают тёмный силуэт и «???». В записи — картинка, локация, здоровье и урон при касании, описание (у боссов — строка из свидетельств, у мини-боссов — своя, у мобов — поведение, у предметов — описание и комбо; имя ещё не найденного напарника по комбо скрыто). Управление: ←/→ (A/D) — вкладка, ↑/↓ (W/S) и колесо мыши — запись, клик по вкладке или строке, Esc — назад. Победы хранятся в сохранении (`defeated`, у боссов — с префиксом `boss:`: у Соседа-моба и Соседа-босса один id); для старых сохранений боссы берутся из счётчика побед. Тест-забег (F4+T) записей не открывает.

Идея бестиария — **Retro_MEGA11**: в титрах есть пункт «Спасибо за идею».

## Оптимизация графики
- **Текст:** отрисованные строки и перенос строк кэшируются (раньше каждый кадр текст рендерился заново, дважды — из-за тени).
- **Масштабирование:** кадр масштабируется в переиспользуемый буфер, а при масштабе 1:1 (режим GPU) копируется без масштабирования; размытый фон по краям окна пересчитывается раз в 8 кадров и рисуется только на полосах вокруг картинки (раньше — каждый кадр на всё окно).
- **Свет и тени:** лучи солнца рисуются заново только когда солнце заметно сдвинулось; тени очищаются и копируются только в прямоугольнике, где они есть; кэш градиентов вытесняет старые записи по одной (раньше сбрасывался целиком, и игра «замирала» на кадр); вспышка не создаёт новую поверхность на каждый кадр; виньетка и градиенты переводятся в формат экрана.
- **Адаптивное качество** («Графика и эффекты → Качество эффектов»: авто / высокое / низкое): в режиме «авто» при устойчивых 45 кадрах/с и меньше сначала отключаются лучи и блики солнца, затем тени становятся простыми пятнами и остаются только самые сильные источники света; когда кадр снова быстрый (около 8 секунд подряд) — эффекты возвращаются. Разовые скачки (загрузка комнаты) на качество не влияют.

## Полный экран
Вместо чёрных полос по бокам рисуется размытое затемнённое продолжение кадра. В «Настройки → Края экрана» можно выбрать «растянуть» на весь экран (пропорции будут искажены).

## Иконка
Положи `icon.ico` рядом с `main.py` (или в `assets/`): она используется в заголовке окна и в панели задач. Без файла показывается запасная иконка. В сборке для GitHub Actions `icon.ico` автоматически становится иконкой `TheShine.exe`.

## Сборка на GitHub Actions
Workflow `.github/workflows/build.yml` на каждый push в `main`/`master` и вручную (Actions → Run workflow) запускает тесты и собирает Windows-версию PyInstaller'ом (папка `TheShine/` с `TheShine.exe`, упаковано в `TheShine-windows.zip` — скачивается из Artifacts). При теге `v*` (например, `git tag v0.1.0 && git push --tags`) архив прикрепляется к GitHub Release. В репозиторий нужно закоммитить `mus/` и `icon.ico` (если нужны музыка и иконка). Сохранения и `crash.log` лежат рядом с exe в `saves/`; папку `mus/` и `config.json` можно положить рядом с exe — они важнее упакованных.
