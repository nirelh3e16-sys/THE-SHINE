# THE SHINE

[English](README.md) · **Русский**

*Top-down рогалик-шутер о самом обычном парне, у которого за шторами спальни начинается конец света.*

THE SHINE — 2D экшен-рогалик на Python + Pygame. Все спрайты, эффекты и звуки рисуются кодом: никаких внешних ассетов, интернета и ключей. Пройди пять странных локаций, собери проклятые дары, реши, кто ты такой, и встреть то, с чего всё началось.

## Идея

- **Каждый дар требует жертвы.** У сильного предмета всегда есть цена: больше урона — но враги быстрее; щит — но после его разрушения ты замедляешься; крылья — но приземление отнимает скорость. Забег не должен сводиться к накоплению урона: предметы меняют *стиль* игры.
- **Выбор запоминается.** События и алтари предлагают украсть, помочь, подраться или убежать. Грехи и свидетельства переходят между забегами и открывают секретную концовку.
- **История через боссов.** Каждый босс — кусочек загадки о THE SHINE: что это, кем он был и что над ним и под ним.
- **Реиграбельность.** Процедурные комнаты, 61 предмет, комбинации и скрытые синергии, 8 персонажей и несколько концовок.

## Быстрый старт (Windows 10/11, Python 3.11+)

```
python -m pip install -r requirements.txt
python main.py
```

Игра запускается на английском; русский включается в *Settings → Language / Язык*.

## Мир

Локации по порядку: **Лес → Пригород → Город → Центр → Врата (THE SHINE)**. Две секретные ветки — **Ад** и **Небеса** — открываются после определённых концовок.

- Каждая локация — процедурно сгенерированный набор связанных комнат: бой, сокровища, магазин, события и комната босса. Боевые комнаты запираются, пока не зачистишь их.
- **Мини-боссы** стоят на пути к каждому боссу и роняют уникальные предметы, которых нет нигде больше.
- **Локации становятся страннее:** в Городе меняется гравитация и перестраиваются стены, Центр глючит и склеивает комнаты из кусочков разных мест, Ад горит, а небесная стража спит, пока ты не тронешь одного из стражей.
- **Боссы:** Лесник, Сосед, Мэр, Хаос, THE SHINE, Бес и Бог — у каждого несколько фаз, а опасные атаки всегда показываются заранее.
- Смена **дня и ночи**, динамические тени, блики и свет (всё отключается в *Settings → Graphics*).

## Персонажи

Роб (стартовый), Лесник, Том, Большая шишка, Глич, Ангел, Дьявол и Душа. У каждого свои здоровье, скорость, размер, стартовые предметы, иногда особенности (Ангел проходит сквозь стены). Закрытые персонажи показывают условие открытия — обычно несколько побед над боссом или определённая концовка.

## Предметы

**61 предмет** лежат в `data/items.json`. У каждого есть уникальный строковый `id` и уникальный номер (его принимает консоль). Предметы бывают пассивными и активными (Q), складываются в комбинации; часть выпадает только с мини-боссов.

### Версия 1.1.0 — тридцать артефактов

Десять библейских, десять древнерусских и десять греческих артефактов в четырёх редкостях: **10 обычных, 10 необычных, 7 редких, 3 божественных**.

| | Библейские | Древнерусские | Греческие |
|---|---|---|---|
| Тема | вера, грех, искупление | природа, духи, судьба | гордыня, героизм, воля богов |
| Примеры | Семь печатей — волна света каждые 7 убийств, но она замедляет. Запретный плод — +40% урона, враги быстрее. Святой Грааль — полное лечение за босса, но обычное лечение слабее. | Топор Перуна — каждая 5-я атака вызывает молнию, остальные слабее на 10%. Игла Кощея — переживаешь смертельный удар раз за этаж, но на время теряешь макс. здоровье. Костяная ступа — давит врагов в комнате, после чего нельзя атаковать. | Огонь Прометея — сильный поджигающий огонь, иногда жжёт и тебя. Ящик Пандоры — случайный эффект, возможно проклятие комнаты. Молния Зевса — удар по линии прицела, затем 2.5 с без атак. |

Как это работает:

- **Полёт:** Крылья серафима и Икара превращают уклонение в короткий полёт над препятствиями; приземление (или перегрев) замедляет.
- **Статусы:** Корона Мораны замораживает, Голова Медузы окаменяет, Огонь Прометея поджигает.
- **Активные:** Книга Откровения (пророчество, иногда ложное), Костяная ступа, Ящик Пандоры, Шлем Аида (невидимость, но без атак), Нить Ариадны (вернуться в прошлую комнату), Молния Зевса.
- **Синергии:** пары вроде Семи печатей + Книги Откровения или Зевса + Перуна меняют работу предметов. Для наборов из трёх предметов есть **три секретные синергии** — найди их сам.

## Концовки

Несколько концовок (хорошая, плохая, секретная, злая и истинная) запоминаются между забегами. Какие из них доступны, зависит от побед над боссами, твоих выборов и собранных свидетельств. Некоторые открывают новых персонажей и локации.

## Бестиарий

Раздел «Bestiary» в главном меню хранит всех открытых боссов, мини-боссов, мобов и предметы. Запись открывается победой над существом или находкой предмета; скрытые синергии не раскрываются.

## Консоль разработчика (F4 + 3)

Открывается во время забега. В отличие от тест-меню, **консоль не включает тест-режим** — прогресс, записи бестиария и концовки засчитываются. Пока консоль открыта, игра на паузе. Команды вводятся по-английски.

| Команда | Что делает |
|---|---|
| `help [команда]` | список команд / справка по одной |
| `give <id\|номер> [...]` | выдать предметы: `give seven_seals` или `give 130` |
| `remove <id\|номер>` | забрать предмет |
| `items [текст]` | все предметы с id, номером, редкостью и темой (фильтр: `items greek`) |
| `inv`, `combos` | твои предметы; все комбо, включая скрытые |
| `teleport <место>` (или `tp`) | `forest`, `suburbs`, `city`, `center`, `shine`, `hell`, `heaven` либо комната текущей локации: `boss`, `miniboss`, `start`, `shop`, `treasure`, `event` |
| `locations` | список целей телепорта |
| `god [on\|off]` | неуязвимость |
| `damage <n>\|reset`, `maxhp <n>\|<h>h`, `hp <n>\|full`, `reset` | урон / макс. здоровье (`maxhp 6h` = 6 сердец), здоровье |
| `coins <n>`, `coins set <n>` | добавить / задать монеты |
| `heal`, `card`, `killall` | полное лечение, выбор из трёх карточек, убить всех врагов в комнате |
| `clear`, `close` | очистить вывод, закрыть консоль |

Tab дополняет команды, id предметов и места; ↑/↓ — история; PageUp/PageDown — прокрутка.

## Для разработчиков

- Код в `game/` (`entities/`, `systems/`, `world/`, `ui/`, `art/`), данные в `data/*.json`. Поведение артефактов — `game/systems/artifacts.py`, консоль — `game/console.py`.
- **Новый предмет:** запись в `data/items.json` (`id`, уникальный `num`, `name`, `desc`, `icon`, `color`, `mods`/`flags`/`active`), иконка в `game/art/`, английский текст в `data/lang_en.json`.
- **Локализация:** исходный язык — русский; английский перевод подставляется при отрисовке по русской строке из `data/lang_en.json`. Тест падает, если остаётся непереведённая строка.
- **Конфиг:** `config.json` рядом с игрой (число комнат, масштаб окна, сид, длина суток, `unlock_all_characters`, …). Сохранения и `crash.log` — в `saves/`.
- **Музыка:** треки кладутся в папку `mus/` (`Forest_Combat.mp3`, `THE_SHINE.mp3`, `Hollow_Sanctuary.mp3`, `spawn_of_darkness.mp3`, …); нет файла — тишина. Полный список — в `game/systems/audio.py`.
- **Иконка / Steam:** `icon.ico` рядом с `main.py` используется как иконка окна; достижения Steam необязательны (`requirements-steam.txt`).
- **Тесты:** `python -m unittest discover tests`; тесты, которым нужен Pygame, пропускаются, если его нет.
- **Сборка:** `.github/workflows/build.yml` на каждый push запускает тесты и собирает Windows-версию PyInstaller'ом.

> **Статус:** версия писалась в среде без возможности запустить Pygame. Запусти игру и при падении смотри `saves/crash.log`.

Издатель и музыка — **FreeDom Studio**. Идея бестиария — **Retro_MEGA11**.
